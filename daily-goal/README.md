# わたしのゴール（短期ゴールページ）

毎日の1問と、自分で決めた短期ゴールを1枚にまとめたページ。
アプリのバナーから開く想定の、検証用プロトタイプです。

```
daily-goal/
├── index.html      ページ本体（これ1枚で完結）
├── gas/Code.gs     バックエンド（Google Apps Script）
└── README.md
```

## 動かし方

`index.html` は **GAS_URL が空のままだとサンプルデータで動きます**。そのまま開けば画面の確認ができます。

```js
const GAS_URL = "";   // ← ここにGASのURLを入れるとライブ動作
```

## バックエンド（Google Apps Script）

1. 新規スプレッドシート →「拡張機能 > Apps Script」→ `gas/Code.gs` を貼り付け
2. `setup()` を1回実行すると、6つのシートが作られます
3. **`questions` シートに問題CSVをインポート**します
4. 「デプロイ > 新しいデプロイ > ウェブアプリ」→ 発行された `/exec` の URL を `index.html` の `GAS_URL` に貼る
5. 「トリガー」で `dailyRollup` を **時間主導型 / 日付ベース / 午前4〜5時** に登録

> **問題データはこのリポジトリに置きません。** 正解が含まれるため、スプレッドシートに直接インポートしてください。

## シートの構成

| シート | 役割 |
|---|---|
| `users` | メールアドレスと内部ID（uid）の対応表 |
| `goals` | uidごとの短期ゴール（種別・期日・単元・必要回数・消化数） |
| `answers` | 回答ログ（uid / 問題ID / 予想 / 選択 / 正誤 / 所要ms） |
| `events` | 来訪・予約ボタン・ゴール保存などの行動ログ |
| `reports` | 「おかしいかも？」で送られた指摘 |
| `questions` | 問題データ |
| `集計` | `dailyRollup` が前日ぶんの漏斗を1行ずつ追加 |

### 人を取り違えない仕組み

**端末ではなくメールアドレスで人を決めます。**

- メールアドレスを持つのは `users` シートの1箇所だけ
- 行動ログには内部IDの `uid` だけを書きます
- 同じメールなら、別の端末でも同じ `uid` に戻ります
- 同じ端末で別のメールを入れれば別の `uid` になるので、家族で共有しても混ざりません

## 正答率の出し方

**まだ誰も解いていない問題に、それらしい初期値は置きません。** 状況で表示を切り替えます。

| モード | 表示 | 条件 |
|---|---|---|
| `tomorrow` | 「正答率は明日わかります」 | 回答がまだ0件 |
| `few` | 「12人中5人が正解」 | 回答が30件未満。**割合にしない** |
| `pct` | 「41%が正解」 | 回答が30件以上 |
| `gov` | 「全国調査では23.3%」＋出典 | `source` に出典がある問題 |

**「全国調査」と「このアプリの利用者」は別の数字なので、ラベルを分けて表示します。**

`RATE_MIN_PCT`（既定30）で、割合表示に切り替わる件数を変えられます。

## 集計の見かた

`集計` シートに前日ぶんが1行ずつ増えます。

| 列 | 意味 |
|---|---|
| ゴール設定者 | その日にゴールを保存した人数 |
| ページ来訪 | ページを開いた人数（ユニーク） |
| 回答 | 1問に回答した人数（ユニーク） |
| 予約ボタン | 「次の1回を予約する」を押した人数（ユニーク） |
| 来訪→予約 | 上記2つの比 |

## 問題データの形式

`questions` シートの列。`tier` は `daily`（全員共通の1問）。

```
id, tier, date, grade, order, subject, unit, source,
question, choice_a, choice_b, choice_c, choice_d, answer_index,
hint, explain, unit_tag, bridge_unit,
teacher_id, teacher_initial, teacher_name, teacher_intro, teacher_msg
```

- `answer_index` は **0から数えます**（choice_a が 0）
- `date` に入れた日に、その問題が出ます（平日ぶんを用意しておく運用）
- `bridge_unit` は解答後に出す「この考え方は◯◯につながります」に使います
- `teacher_*` は**すべて空で運用しています**。ひとことは `explain` の末尾に入れてください
